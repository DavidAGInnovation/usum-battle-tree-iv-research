`Internal display code (tr_type)` is the decimal `trainer::TrType` field stored beside each trainer record. The Battle Tree selection code copies this field into the NPC selection item for trainer icon/display handling; it is not a localized name string. ## Interpretation notes

- IDs `0–189` are ordinary Battle Tree trainer records and use the range rule: `0–49 → 19`, `50–69 → 23`, `70–89 → 27`, and `90+ → 31`.
- IDs `190–205` are the Battle Legend and featured-trainer records selected by the retail Battle Tree code. They are all in the `90+` branch and therefore receive 31 IVs on the normal trainer path.
- ID `206` is Lillie’s USUM scouted-partner record. Its partner constructor passes `31` directly rather than using the range lookup.
- IDs `207–209` are Battle Agency event records (Sophocles, Giovanni, and Grunt). Their event constructor passes `BattleFesDefine::POWER = 0x1f`, so they also receive 31 IVs in all six stats.
- Rada is archive ID `80` and therefore has `27` IVs when that archive record is created through the ordinary trainer path. The separate default-partner constructor is a different path and hardcodes `31`; see the partner note in the main report.
